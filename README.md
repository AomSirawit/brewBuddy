# ☕ คู่มือการใช้งาน brewBuddy (LINE Bot)
เมื่อเชิญบอท `brewBuddy` เข้ามาในกลุ่ม LINE ของคุณ คุณสามารถใช้บอทเพื่อช่วยรวมออเดอร์กาแฟหรือเครื่องดื่มต่างๆ ภายในทีมได้อย่างง่ายดาย

---

## 1️⃣ การเชิญบอทเข้ากลุ่ม
*   **เชิญเข้ากลุ่ม:** เพียงแค่เชิญ (Invite) บอท `brewBuddy` เข้ามาในกลุ่ม LINE ที่ต้องการรวมออเดอร์
*   **การเชื่อมต่อ:** ทันทีที่บอทเข้ากลุ่ม บอทจะทักทายและบันทึกข้อมูลว่ากำลังทำงานอยู่ในกลุ่มไหนโดยอัตโนมัติ (✅ บอทเข้ามาแล้ว!)

## 2️⃣ การเปิดรับออเดอร์ (สร้างโพล)
เมื่อถึงเวลาอยากจะสั่งน้ำ ให้ผู้ดูแล (Admin) พิมพ์คำสั่งเปิดโพลลงในกลุ่ม
*   **พิมพ์คำสั่ง:** `/coffee` (หรือรหัสผ่าน Admin ตามที่ตั้งไว้ในระบบ)
*   **ผลลัพธ์:** บอทจะตอบกลับว่าเปิดรับออเดอร์แล้ว และส่ง **Flex Message (หน้าโพล)** มาให้สมาชิกทุกคนกดสั่ง

## 3️⃣ วิธีการสั่งเครื่องดื่ม (สำหรับสมาชิก)
เมื่อเห็นกล่องข้อความโพลเปิดรับออเดอร์ สมาชิกสามารถกดเลือกได้ตามต้องการดังนี้:

### สั่งเมนูที่มีในปุ่ม
1.  กดเลือก **เมนู** ที่คุณต้องการ (เช่น ☕ อเมริกาโน่ เย็น, 🍦 ลาเต้ เย็น, 🫧 มัทฉะ ลาเต้, 🧋 ชาไทย)
2.  บอทจะแสดงหน้าจอให้ **เลือกระดับความหวาน** (🍬 หวานปกติ, 🔽 หวานน้อย, 🚫 ไม่หวาน, ⬆️ หวานมาก)
3.  พอกดเลือกความหวานเสร็จ บอทจะตอบกลับว่าบันทึกออเดอร์เรียบร้อย

### สั่งแบบระบุเอง (นอกเหนือจากเมนู)
1.  กดปุ่ม **"📝 พิมพ์สั่งเอง"**
2.  บอทจะส่งข้อความมาบอกให้พิมพ์สิ่งที่ต้องการ
3.  ให้**พิมพ์เครื่องดื่มของคุณ**ส่งไปกลับในแชทกลุ่มเลย เช่น `"คาปูชิโน่เย็น ไม่หวาน"` หรือ `"ชาเขียวปั่น เพิ่มวิปครีม"`
4.  บอทจะบันทึกออเดอร์เหล่านั้นให้

### กรณีไม่ต้องการสั่ง
*   ถ้าวันนี้ไม่ต้องการกิน ให้กดที่ปุ่ม **"💧 ไม่สั่ง"** บอทจะบันทึกไว้ให้รู้ว่าคุณไม่ได้รับ

## 4️⃣ การปิดรับออเดอร์และดูสรุปยอด
เมื่อสมาชิกกดสั่งครบแล้ว หรือหมดเวลาสั่ง:
1.  **ปิดโพลด้วยมือ:** แอดมินสามารถกดปุ่ม **"🛑 ปิดรับออเดอร์ (แอดมิน)"** ที่อยู่ด้านล่างสุดของโพลคำสั่งซื้อ
2.  **หมดเวลาโพล:** โพลที่เปิดไว้จะตั้งเวลาหมดอายุอัตโนมัติตามระบบ (เช่น เช้าวันถัดไป 08:00) และจะไม่สามารถกดสั่งย้อนหลังในโพลนั้นได้อีก
3.  **การแสดงสรุปผล:** ทันทีที่โพลถูกปิด บอทจะส่งข้อความแสดง **"สรุปยอดสั่งซื้อ"** ไปที่กลุ่ม โดยจะจัดกลุ่มเมนูที่เหมือนกัน แจ้งจำนวนรวม และ**บอกรายชื่อสมาชิก (👤)** ว่าใครสั่งแก้วไหนบ้าง ทำให้คนสั่งร้านและคนเก็บเงินตรวจสอบได้ง่ายมาก!
